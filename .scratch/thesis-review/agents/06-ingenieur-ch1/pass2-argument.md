# Second-pass argument review: thesis/ingenieur/ch1_introduction.tex

Dimensions D1, D2, D4, D6 and D10 only. This review covers the text as it stands at HEAD plus the working tree (the file has no uncommitted diff). Script report used as given: 0 FAIL, 5 WARN, 60 PASS.

## 1. Verdict

**Ch1 is not correct as it stands. It is ready after fixes, and none of them needs a rework.**

- **The first-pass fixes mostly hold.** The reflex path now skips interpretation, not validation. The anchor/endpointer argument, the hold/no-op split, the "designs the first two" hand-off and the named criteria are correct, and they agree with Ch3 and the code.
- **One BLOCKER remains, and the first pass missed it.** l.44-46 places the swarm controller on the Raspberry Pi. Ch3, prd Figure 1 and `runtime/bus.py` all place the state machine and the controller on the workstation. The rewrite's new offline-definition sentence (l.40-42) and l.61 now lean on that wrong placement.
- **The rewrite introduced one MAJOR.** The new experiment description credits the latency experiment with measuring keyword false accepts. It does not measure them: `eval/exp2.py` says it quotes them from the keyword spotter's held-out evaluation.
- **Three older MAJORs survive the rewrite:**
  - "networking disabled" is still unreconciled with the Wi-Fi bus.
  - "A misheard command must not become motion" is an objective the three layers cannot enforce, as the chapter itself concedes.
  - The clamp "at the integrator" exists only in the kinematic simulator, where zero collisions holds by construction. The chapter does not say so.
